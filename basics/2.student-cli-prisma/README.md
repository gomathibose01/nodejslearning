# ◮ Student Management System (Prisma CLI)

A modern, type-safe **Command Line Interface (CLI)** application built using **Node.js (ESM)** and the **Prisma ORM**. This workspace demonstrates how to replace raw SQL text strings with an automated, type-safe data mapper executing natively inside the terminal [💡, 💡].

---

## 📂 Project Architecture

```text
basics/student-cli-prisma/
├── prisma/
│   └── schema.prisma     # 📜 Database engine configuration & model layout schemas
├── data/
│   └── dev.db            # 📁 Isolated SQLite Database File (auto-generated by Prisma)

│   ├── manage-db.js      # 🛠️ Script 1: Automatically pushes tables & seeds mock data

```

## 🚀 Setup & Execution Guide

Follow these exact terminal steps sequentially from your workspace shell root to install, provision, and launch the application [💡]:

### 1. Step Into the Target Project Directory
```bash
cd ~/nodejslearning/basics/student-cli-prisma
```

### 2. Download Project Engine Dependencies (Run Once)
Download the local Prisma CLI compiler tools and Client engine binaries into your workspace path safely without root-level privileges [💡]:
```bash
npm install
```

### 3. Provision the Database & Generate Type-Safety
Run the automated initialization command shortcut [💡]. This invokes `prisma db push` to analyze your schema, carve out the local `dev.db` storage binary file on your disk out of thin air, and instantly compile a customized, auto-completed JavaScript client tailored specifically to your data columns [💡]:
```bash
npm run db-init
```
*   **Expected Log Output:** `✅ Prisma database successfully initialized and seeded.`
*   *Note: This script seeds your distinct database profile characters (**Evan Rogers & Fiona Gallagher**) automatically.*

### 4. Launch the Interactive CLI Dashboard Panel
Boot up your terminal application loop process [💡]:
```bash
npm run cli-manage
```

### 5. Daily Operation Terminal Shortcut Controls
*   Press **`1`** to output a type-safe database records list directly into an aligned terminal data matrix loop (`console.table`).
*   Press **`2`** to add a new record securely to the SQLite table file via pure JavaScript objects—no raw SQL text strings required [💡].
*   Press **`3`** to disconnect the engine interface layer cleanly and terminate the shell tool workspace loop safely.



// 1. Raw SQL Approach (The old student-cli / student-web way)
// Written as text strings executed blindly by the engine at runtime.
CREATE TABLE IF NOT EXISTS students (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL,
    grade TEXT NOT NULL
);

// 2. Prisma Schema Approach (The new student-cli-prisma way)
// Written as clear, declarative data models compiled before your code ever runs.
model Student {
  id    Int    @id @default(autoincrement())
  name  String
  email String @unique
  grade String
}
